## 1. 产品概述

个人 AI 助手工作台是本地 Web 应用的首页（`/`），在同一页面管理 **待办**、**日程**、**定时任务**，并通过右侧 **个人助手** 用自然语言创建内容、生成 AI 初步结果、多轮修改与历史回溯。

**能力分层**：定时任务（调度）→ 物化待办（工作单元）→ 个人助手 AI（待办层）；定时任务 Tab **不直接调用大模型**。

## 2. 访问与运行

| 项 | 说明 |
|----|------|
| 前端 | http://localhost:5175（首页即个人工作台） |
| 后端 | http://localhost:3100 |
| 启动 | 仓库根目录 `pnpm install` → `pnpm dev` |
| 数据 | SQLite 持久化（`server/data/project-manager.db`） |
| AI 生成 | 配置 `server/.env` 中 `LLM_API_KEY`；未配置时自动降级为规则模板 |

开发域（需求列表、仓库、扫描等）从工作台顶栏 **开发域** Tab 进入（`/dev-dashboard`）；开发域内顶栏 **个人工作台** 可返回首页。

## 3. 考题范围交付（已全部实现）

依据 [个人工作台.md §1.2–1.3](./个人工作台.md#13-范围说明)，以下能力均已上线：

| 模块 | 交付要点 |
|------|----------|
| **页面框架** | 三 Tab（日程与事项 / 定时任务 / 开发域）；待办 36% + 日程 64% + 助手 340px；统计胶囊实时联动；1100 / 900 / 640 响应式 |
| **待办管理** | 四态筛选、手动添加、完成归档、逾期标记、AI 入口条与面板、历史已完成区 |
| **日程管理** | 0–24h 时间轴、小月历、飞书/钉钉/Outlook/本地四渠道开关、15 分钟去重、多来源标签 |
| **定时任务** | 每天/每周/每月规则；到期物化待办（日滚动 5 条）；后台调度器 |
| **个人助手** | 自然语言三分流（待办 / 日程 / 定时任务）；7 类能力判定；11 条考核话术自动化回归 |
| **AI 结果** | 异步生成与轮询、全屏预览、多轮修改、历史对话、确认后自动完成待办 |
| **交互与非功能** | 弹窗 CRUD、Soul 设置、边界提示；数据落库（超出 Demo「内存即可」基线） |

**考题 Demo 约定**：外部日历 OAuth **允许模拟**——当前以种子数据 + 渠道开关演示，满足产品文档要求。

## 4. 考题范围外增强（已实现）

在考题必交项之外，额外交付了以下能力：

| 增强项 | 说明 |
|--------|------|
| **SQLite 持久化** | 待办、日程、定时任务、助手会话、AI 版本均落库，重启不丢数据 |
| **Soul 偏好持久化** | 语气与自定义说明写入 settings，影响生成结果 |
| **LLM 生成与修订** | `retrieveForTodo` → LLM 生成/修订 HTML；失败或无 Key 时降级规则模板 |
| **待办知识库 RAG（E1–E3）** | 规则检索（日程窗、历史结果、同类型片段）注入生成与多轮修改上下文 |
| **五层助手架构** | Intent 路由、Tool 注册、护栏、编排器、指标；SSE 对话与 refresh 契约 |
| **开发域并存** | 同一 Monorepo 内保留需求/仓库/扫描等开发驾驶舱（`/dev-dashboard` 起） |

> RAG 在考题中标注为「后续迭代」，上述 E1–E3 为提前落地的内部闭环能力。
