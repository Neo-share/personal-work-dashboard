```text
client: PersonalWorkbenchPage / personal-workbench/* 
  → tRPC (todos / schedule / recurringTasks / personalWorkbench / assistant)

server: router (Zod) → *-service → SQLite
shared: types.ts · assistant-contract.ts
```
