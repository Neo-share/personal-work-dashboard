4. 个人助手五层架构（F0–F4）

  → personal-assistant-service（薄封装）

4.2 四层护栏（F3+ 安全增强）

个人助手链路采用确定性代码护栏（不依赖 LLM 判断）。规则细则见 TODO/guardrail-enhancement.md；向外交付摘要见交付说明 §4.1。

层检查项失败动作
输入空消息、超长（2000 字）、提示注入、高风险敏感动作SSE blocked，不写库
意图低置信度 + 敏感动作词SSE blocked
工具白名单、Zod 参数、modifyTodoId 归属拒绝调用
输出内部文件路径脱敏为 [路径已隐藏]

2026-06 增强要点：normalizeGuardrailText（NFKC / 零宽字符 / 空白折叠）；约 24 条注入模式（中英双语、模板分隔符、越狱）；敏感动作输入层直拦（sensitive_action）；指标 pw.guardrail.blocked。

5. AI 与 RAG 架构

5.1 AI 初步结果与修订

createTodo / triggerAiGeneration
  → internal-knowledge-retriever.retrieveForTodo（R0 规则检索）
  → llm-ai-result-generator（OpenAI 兼容 API）
  → 失败或无 LLM_API_KEY → 规则模板降级
  → todo_ai_results 版本递增 + 助手会话消息

5.2 内部 RAG（E1–E3，SQLite 闭环）

检索源：当日日程窗、历史同类型 AI 结果、已完成待办片段等。不依赖外部 OAuth 或 MCP。

5.3 外部 MCP（F4，可选）

用户消息含飞书文档 URL 时，经 HTTP 桥接（FEISHU_MCP_HTTP_URL）拉取摘要注入 externalSnippets；未配置时自动降级，不影响主链路。
