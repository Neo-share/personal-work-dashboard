1. 产品概述

个人 AI 助手工作台是本地 Web 应用的首页（/），在同一页面管理 待办、日程、定时任务，并通过右侧 个人助手 用自然语言创建内容、生成 AI 初步结果、多轮修改与历史回溯。

能力分层：定时任务（调度）→ 物化待办（工作单元）→ 个人助手 AI（待办层）；定时任务 Tab 不直接调用大模型。

4.1 个人助手四层护栏（安全增强）

定位：个人助手（/api/chat?context=personal）在规则编排链路上的确定性代码护栏，不依赖大模型或提示词判断；降低误触发、越权执行与提示注入风险。规则细则见 TODO/guardrail-enhancement.md。

与考题关系：考题 TL1-08 要求边界提示与 blocked 交互；F3 基础护栏已满足考题。本节为 2026-06 增强：扩展注入模式表、输入归一化、高风险指令输入层直拦。

四层检查与失败动作

层检查项失败动作
输入空消息、超长（2000 字）、提示注入、高风险敏感动作SSE blocked，不写库
意图低置信度 + 敏感动作词SSE blocked，不自动执行副作用工具
工具工具白名单、Zod 参数、modifyTodoId 归属SSE blocked 或拒绝调用
输出回复含内部文件路径脱敏为 [路径已隐藏] 后下发

2026-06 增强要点

项说明
输入归一化normalizeGuardrailText：NFKC 折叠、零宽字符处理、空白折叠（参考 OWASP LLM01 Prompt Injection Prevention Cheat Sheet）
注入模式扩展约 24 条正则，覆盖指令覆盖、系统提示词提取、角色劫持/越狱、模板分隔符（[INST]、<|im_start|> 等）、XSS 片段；中英双语
敏感动作扩展批量删除/清空待办·日程·定时任务、DROP TABLE、delete all、rm -rf 等；输入层直接拦截（code: sensitive_action），不依赖意图置信度
可观测拦截写入 MetricsLedger：pw.guardrail.blocked { layer, code }

前端可见 blocked 码（摘要）

code典型场景

4.2 性能与 LLM 成本优化（2026-06 增强）

定位：在不影响考题功能的前提下，降低 LLM Token 消耗与调用次数、缩短多轮修订延迟，并提供运行时用量与链路时延观测。

策略说明

9. MCP 配置说明

本项目的 MCP 分两层：应用运行时（个人助手拉取飞书文档上下文）与 Cursor IDE 开发侧（可选，便于调试文档 MCP）。二者独立配置，互不依赖。

9.1 应用运行时：飞书 Document MCP（F4）

作用：用户在个人助手消息中粘贴飞书文档链接时，服务端经 HTTP 桥接拉取文档摘要，注入 ContextRetriever.externalSnippets，参与 AI 生成/修订上下文。

与考题关系：考题 RAG（E1–E3）为 SQLite 内部检索，不依赖 MCP；F4 为考题外增强，未配置时不影响主链路（自动降级为纯 DB 上下文 + 规则/LLM 模板）。

配置步骤

  1. 复制环境变量模板：cp server/.env.example server/.env
  2. 在 server/.env 中设置（示例见 .env.example）：
变量必填说明
FEISHU_MCP_HTTP_URL是本地 MCP HTTP 桥接地址，如 http://127.0.0.1:3333/mcp/feishu/get_doc_content
FEISHU_MCP_TIMEOUT_MS否单次请求超时，默认 15000
FEISHU_MCP_MAX_DOCS否每条消息最多拉取文档数，默认 3
FEISHU_MCP_EXCERPT_CHARS否单文档摘要最大字符，默认 1500

3. 重启 pnpm dev 使配置生效。

HTTP 桥接约定（服务端 feishu-doc-client.ts 实现）

POST {FEISHU_MCP_HTTP_URL}
Content-Type: application/json

{ "doc": "<飞书文档 URL 或 token>", "use_user_token": true }

响应 JSON 须含 content 或 markdown 字段（Markdown 正文）。飞书凭证与 OAuth 由桥接层自行管理，勿写入本仓库或交付文档。

触发方式：个人助手输入含飞书文档 URL 的消息（支持 feishu.cn / feishu.net / larksuite.com 的 wiki/docx/docs 链接）；无 URL 或未配置 MCP 时不发起外部请求。

相关代码：server/src/assistant/mcp-context-retriever.ts · server/src/assistant/mcp/feishu-doc-client.ts
